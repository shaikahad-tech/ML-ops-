03 / System Design

The architecture

Six modules. One pipeline. Zero external dependencies.

01

Data Generation

Synthetic customer records with a logistic churn signal. 5,000 rows, calibrated to a 26.5% positive rate.

mlops/data/generate.py
02

Preprocessing

ColumnTransformer with StandardScaler for numerics and OneHotEncoder for categoricals. Wrapped in a single Pipeline.

mlops/data/preprocess.py
03

Training

RandomForestClassifier with balanced subsample weights. Hyperparameters driven entirely by YAML config.

mlops/train.py
04

Experiment Tracking

MLflow logs params, metrics, and model artifacts. Models are registered to the Model Registry for versioning.

mlflow + registry
05

Serving

FastAPI loads the latest registered model. The same Pipeline artifact guarantees train/serve parity.

mlops/serving/app.py
06

CI / CD

GitHub Actions runs tests on Python 3.11 and 3.12, a training smoke test, and Ruff lint on every push.

.github/workflows/ci.yml
04 / Command Line

Run it locally

Three commands. That's all it takes.

# Install
$ pip install -r requirements.txt && pip install -e .

# Train the model
$ python run.py train --config configs/default.yaml
Generated 5000 rows | churn rate=0.265
Training complete | f1=0.861 | roc_auc=0.858

# Serve the API
$ python run.py serve --port 8000
Uvicorn running on http://0.0.0.0:8000
